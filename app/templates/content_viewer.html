Kadane's Algorithm

Dynamic Programming Arrays Medium

What is it?

Kadane's Algorithm is an efficient method for finding the maximum sum of a contiguous subarray within a one-dimensional array of numbers. It operates in O(n) time complexity, making it significantly faster than brute force approaches.

Key Concepts

  • Maintains running maximum sum ending at current position
  • Resets when sum becomes negative
  • Tracks global maximum throughout iteration

Complexity Analysis

Time Complexity

O(n)

Space Complexity

O(1)

Use Cases

Stock Trading

Find the best time window to maximize profit

Time Series Analysis

Identify periods of highest cumulative value

Image Processing

Finding regions of highest intensity

Implementation

kadane.py 
def kadane_algorithm(arr):
    """
    Find the maximum sum of a contiguous subarray.

    Args:
        arr: List of integers (can contain negative numbers)

    Returns:
        int: Maximum sum of contiguous subarray

    Time Complexity: O(n)
    Space Complexity: O(1)
    """
    # Handle edge case: empty array
    if not arr:
        return 0

    # Initialize variables
    max_current = max_global = arr[0]

    # Iterate through array starting from second element
    for i in range(1, len(arr)):
        # Key decision: extend current subarray or start new one
        max_current = max(arr[i], max_current + arr[i])

        # Update global maximum if current is larger
        if max_current > max_global:
            max_global = max_current

    return max_global

Kadane.java 
public class Kadane {

    /**
     * Find the maximum sum of a contiguous subarray.
     *
     * @param arr Array of integers
     * @return Maximum sum of contiguous subarray
     *
     * Time Complexity: O(n)
     * Space Complexity: O(1)
     */
    public static int kadaneAlgorithm(int[] arr) {
        // Handle edge case: empty array
        if (arr == null || arr.length == 0) {
            throw new IllegalArgumentException("Array cannot be empty");
        }

        // Initialize variables
        int maxCurrent = arr[0];
        int maxGlobal = arr[0];

        // Iterate through array starting from second element
        for (int i = 1; i < arr.length; i++) {
            // Key decision: extend current subarray or start new one
            maxCurrent = Math.max(arr[i], maxCurrent + arr[i]);

            // Update global maximum if current is larger
            maxGlobal = Math.max(maxGlobal, maxCurrent);
        }

        return maxGlobal;
    }

    /**
     * Result class to hold sum and indices
     */
    public static class SubarrayResult {
        public int maxSum;
        public int startIndex;
        public int endIndex;

        public SubarrayResult(int maxSum, int startIndex, int endIndex) {
            this.maxSum = maxSum;
            this.startIndex = startIndex;
            this.endIndex = endIndex;
        }
    }

    /**
     * Returns maximum sum along with start and end indices.
     */
    public static SubarrayResult kadaneWithIndices(int[] arr) {
        if (arr == null || arr.length == 0) {
            return new SubarrayResult(0, -1, -1);
        }

        int maxGlobal = arr[0];
        int maxCurrent = arr[0];
        int start = 0, end = 0, tempStart = 0;

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > maxCurrent + arr[i]) {
                maxCurrent = arr[i];
                tempStart = i;
            } else {
                maxCurrent = maxCurrent + arr[i];
            }

            if (maxCurrent > maxGlobal) {
                maxGlobal = maxCurrent;
                start = tempStart;
                end = i;
            }
        }

        return new SubarrayResult(maxGlobal, start, end);
    }

    // Test cases
    public static void main(String[] args) {
        // Example 1: Mixed positive and negative
        int[] arr1 = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
        int result = kadaneAlgorithm(arr1);
        System.out.println("Maximum subarray sum: " + result);  // Output: 6

        // Example 2: With indices
        SubarrayResult detailed = kadaneWithIndices(arr1);
        System.out.printf("Max sum: %d, from index %d to %d%n",
            detailed.maxSum, detailed.startIndex, detailed.endIndex);
    }
}

Why is this O(n)?

We traverse the array exactly once, performing constant-time operations at each step (comparisons and additions). No nested loops or recursive calls are needed, making this algorithm highly efficient even for very large arrays.
